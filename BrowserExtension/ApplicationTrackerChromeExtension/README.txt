APPLICATION TRACKER JOB CAPTURE

1. Extract this ZIP to a permanent folder. Do not delete that folder after installation.
2. Open chrome://extensions in Chrome.
3. Enable Developer mode.
4. Click Load unpacked.
5. Select the extracted ApplicationTrackerChromeExtension folder.
6. Pin the extension from Chrome's Extensions menu.

The local Application Tracker must be running before you click Save to Application Tracker.
The extension captures a page only when you click its button.
